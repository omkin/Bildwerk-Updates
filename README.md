# Bildwerk – Downloads

Hier liegen die fertigen Windows-Pakete von Bildwerk. Die neueste Version steht unter [Releases](../../releases/latest):

- `Bildwerk-Setup-<Version>.exe` – Installer (aktualisiert sich danach selbst)
- `Bildwerk-<Version>-portable.exe` – läuft ohne Installation

Die übrigen Dateien (`latest.yml`, `.blockmap`) braucht das Programm für die automatische Aktualisierung.
